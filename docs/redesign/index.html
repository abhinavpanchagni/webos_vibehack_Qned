In the interactive launcher, use ← / → to explore, Enter to select, ↓ to open apps and ↑ from the first app row to return. The mouse and scroll wheel work too. Desktop browsers cannot launch TV applications; selecting one will report that it cannot open.

Local review only. No TV deployment has been performed. Browser tests use a simulated webOS service bridge; real app switching, Magic Remote hardware and TV frame pacing remain to be checked after deployment approval.
